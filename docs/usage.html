Using it

The bar icon

Click the arXiv icon to open or close the panel; right-click it to refresh the lists. Hovering shows the current tab, how many preprints it lists and how recent the newest one is.

The panel

Each category you follow has a tab, plus a ★ tab for starred papers. A row shows the title, the authors, and a line with the submission age, the category (marked cross-list when the paper belongs primarily to another one), the identifier, and report once a report exists. Select a row to show its abstract and the authors' comment.

With the mouse: click a row for its abstract, right-click it for the PDF, or use the star, page and PDF buttons on its right.

Starring any paper

Press a and paste an identifier in any of these forms, with or without a version: 2401.12345, arXiv:2401.12345v2, math/0309285, or an arxiv.org/abs/… or arxiv.org/pdf/… link. The paper is looked up and lands in the ★ tab.

Reports

Pressing S starts a background run over the starred papers that have no report yet. For each one it:

  1. downloads the LaTeX source from arXiv, keeping only text files (.tex, .bbl, .bib, .sty, .cls), or the PDF when the paper has no source;
  2. runs your AI engine on it with the report prompt, in the sandbox unless you turned it off;
  3. writes <identifier>-<title>.md to your reports folder, headed by the title, authors, link, and a line saying when and by which engine and model it was generated.

Notifications tell you when the run starts and how it ended. Only one run goes at a time, and every finished report is recorded immediately, so an interrupted run keeps what it did. To regenerate a report, delete its Markdown file and press S again.

A short paper takes a minute or two; a long one longer, and it uses more of your AI plan.

Reading

Press v to open the local report viewer, a small web server on 127.0.0.1 (port 8791 by default) that lists your reports, newest first, and renders each one with its mathematics typeset by KaTeX. The first time, it downloads KaTeX and marked once; after that it works offline.

The viewer's addresses carry a secret that changes each time it starts, so other accounts on the computer cannot read your reports through it. A bookmark therefore stops working when you log out: open the reports with v instead.

The reports are plain Markdown with LaTeX mathematics, so they also read well in any Markdown editor, Obsidian, or a notes repository.

Refreshing

The lists refresh every 30 minutes (configurable). The bar may hold several copies of the widget, one per monitor; they share one fetch through a disk cache, so arXiv sees one request per category. When arXiv rate-limits its API (HTTP 429), which it sometimes does for hours, each tab keeps its last list with a warning, and the plugin retries after 2 minutes, then 4, and so on up to the refresh interval.

Scripting and keybindings

The widget answers omarchy-shell io.github.pierrecagne.arxiv <command>:

CommandEffect
toggle, open, closeShow or hide the panel
refreshRefetch every tab
category <code>Switch tab, e.g. category math.CT or category starred
star <identifier>Look a paper up and star it
summariseWrite the missing reports
reportsOpen the report viewer

For example, in ~/.config/hypr/bindings.lua:

o.bind("SUPER + ALT + A", "arXiv", "omarchy-shell io.github.pierrecagne.arxiv toggle")
