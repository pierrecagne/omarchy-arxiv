Install

Read the code first

This plugin was vibe coded with Claude Opus 5.5, and Omarchy plugins run unsandboxed inside omarchy-shell with your permissions. Check the source before installing: a handful of short QML, JavaScript and Python files, plus the prompts.

Requirements

WhatWhyNotes
Omarchy 4 (Quattro shell)The bar and panelShips python3, used by the helpers.
An AI engineReportsClaude Code, Codex, or a command-line LLM tool. Browsing works without one.
bwrap (bubblewrap)Sandboxing CodexOnly with Codex: omarchy pkg add bubblewrap.
pdftotext, pdfinfo (poppler)PDF-only papersOptional. Most arXiv papers come with LaTeX source.

Install the plugin

omarchy plugin add https://github.com/pierrecagne/omarchy-arxiv.git --enable

The arXiv icon appears in the center of the bar. Move it with, for example, omarchy bar move io.github.pierrecagne.arxiv --section right.

Set the categories you follow, and who the reports are for:

omarchy bar set io.github.pierrecagne.arxiv categories "math.CT, cs.LO, cs.PL"
omarchy bar set io.github.pierrecagne.arxiv reader "a working mathematician in categorical logic and type theory"
omarchy bar set io.github.pierrecagne.arxiv reportStyle Theory

Category codes are listed in arXiv's category taxonomy. All the settings are on the configuration page.

Set up an AI engine

Claude Code (default)

Install Claude Code and log in once by running claude in a terminal. Reports use your Claude plan or API account.

The sandbox relies on Claude Code's --restricted mode (tested with Claude Code 2.1.295). If your version lacks it, the plugin refuses to run sandboxed and says so: update Claude Code, or turn the sandbox off.

Codex

omarchy bar set io.github.pierrecagne.arxiv engine Codex
omarchy pkg add bubblewrap   # for the sandbox
codex login

Reports use your ChatGPT plan or OpenAI API account. See Codex and the sandbox if Codex keeps its login in the system keyring.

Any other model

Any command that reads a prompt on standard input and prints Markdown will do; the paper's text is included in the prompt. For example, with Simon Willison's llm or with Ollama:

omarchy bar set io.github.pierrecagne.arxiv engine "Custom command"
omarchy bar set io.github.pierrecagne.arxiv customCommand "llm -m gpt-4.1"
# or: "ollama run qwen3"

A custom command runs with your permissions: the sandbox does not apply to it. Details.

First run

  1. Click the arXiv icon. The newest preprints of each category load in their tabs.
  2. Move to a paper with ↑ ↓ and press s to star it.
  3. Press S. A notification says the reports are being written, and another when they are ready.
  4. Press v to read them in your browser.

Update

omarchy plugin update io.github.pierrecagne.arxiv

Omarchy shows the changes before applying them.

Remove

omarchy plugin remove io.github.pierrecagne.arxiv

To delete its state, cache and the downloaded reader assets as well:

rm -rf ~/.local/state/io.github.pierrecagne.arxiv ~/.cache/io.github.pierrecagne.arxiv

Your reports folder (~/Documents/arxiv-reports by default) is left alone.
